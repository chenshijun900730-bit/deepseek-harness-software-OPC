## 2. 功能详情（Release Notes 素材）

### 2.1 子部门实时思考/对话（核心功能）

- **数据通路**：DSH 宿主侧新增 `/company-api/agent-transcript?sessionId=`——存活会话读内存事件（实时、零压力），已结束会话读一次持久日志并缓存 5s；`/company-api/canvas` 与 `/company-api/tokens` 快照携带 `sessionId` + `live` 标记。
- **转录折叠**（`company-r2/lib/transcript.js`，纯函数可单测）：`user/message`/`assistant/message`/`tool/result`/`assistant/chunk` → 任务要求、💭 Think 思考、💬 对话正文、🛠 工具调用+结果；`assistant/chunk` 增量组装流式半成品（思考边生成边可见）。真实 1420 事件持久日志验证通过。
- **三个展示面**：
  1. 主界面右下角悬浮对话坞（输入框上方）：自动弹出、聊天气泡、Markdown 渲染、Think 行首行摘要（点击展开）、流式光标、可拖拽/折叠/✕；
  2. 🏢 Company 面板顶部「部门实时对话」直播区（有活动自动出现）；
  3. 面板完整转录视图（点 Tokens/子代理行或对话卡片）+ `/company` 画布调用卡「💭 查看实时思考/对话」模态。
- **失败降级**：旧引擎未更新时转录视图显示明确提示，不假死。

### 2.2 画布（总监大画布）

- 组织视图文件交接连线常驻（绿/橙/灰虚 + 📄 图标 + 悬停说明），图例同步更新；
- 拖拽部门节点时全部连线与图标实时跟随；
- 画布默认显示，与列表通过「显示详细信息 / 显示画布」按钮切换（覆盖层抽屉，收起时列表占满面板、iframe 卸载停轮询）。

### 2.3 面板与主题

- 空会话自动退回「全部」并提示（修复 autoScope 回退死循环）；
- 主题三态切换，全部硬编码颜色改为 CSS 变量，画布 iframe 经 `?theme=` + postMessage 联动。

## ✨ v1.2.0 · 子部门实时思考/对话可见

子部门在接到项目总控要求执行时，总监现在能**实时看到它们的思考与对话**——像看主界面一样，边生成边显示。

### 🆕 新增

- **子部门实时思考/对话**（核心）
  - 新接口 `/company-api/agent-transcript`：存活会话实时读、已结束会话读持久日志；
  - 主界面右下角自动浮出「💭 部门实时对话」对话坞：聊天气泡、Markdown、Think 思考行、工具调用+结果、流式输出（✍️ 正在输出▍）；可拖拽/折叠/✕（✕ 后下一次新调用自动再弹出）；
  - 🏢 Company 面板顶部同步直播区；点 Tokens/子代理行或对话卡片看完整转录；
  - 总监大画布调用卡新增「💭 查看实时思考/对话」模态。
- **面板主题选择**：🌑 深色 / ☀️ 浅色 / 🌓 跟随系统，选择持久化，画布同步换肤。

### 🔧 修复与优化

- 对话坞/直播区流式重绘（思考文字逐段实时增长，不再只显示第一帧）；
- 对话坞可**滚动预览**：长对话内容不再被压缩裁剪，向上滚动预览历史时不被流式重绘拽回顶部，位于底部则自动跟随新输出；
- 画布文件交接连线**常驻**：绿=已完成、橙=下一步、灰虚=未开始，任务完结后不再消失；拖拽部门节点时连线实时跟随；
- 画布默认显示，「显示详细信息」按钮切换到任务/Tokens/子代理列表（再点返回画布）；列表不再被画布挤压；
- 空会话自动退回「全部」视图并提示（修复作用域回退循环）。

### ✅ 验证

- 31 个单元测试全过（新增 8 个转录单测）；真实持久日志与运行中实例逐项实测通过。
