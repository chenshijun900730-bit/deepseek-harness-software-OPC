# PRODUCT_SPEC — TASK-20260815-004

> 负责人：Planner（deepseek-v4-pro / high）。

## 1. 产品目标
为演示应用增加本地待办列表：用户可新增待办、标记完成，数据持久化到浏览器 localStorage。

## 2. 用户故事
- 作为用户，我输入待办并点击添加后，列表立即出现该待办。
- 作为用户，我勾选完成一项待办后，刷新页面该项仍为完成状态。

## 3. 范围（In Scope）
- 新增待办输入框与添加按钮；列表渲染；勾选切换完成状态；localStorage 持久化与读取。

## 4. 非目标（Out of Scope）
- 不做账号、云同步、编辑/删除/拖拽排序、移动端适配。

## 5. 可观察验收标准（草案）
1. 输入文本点击添加 → 列表出现该项；2. 刷新后该项仍存在且状态一致；3. 勾选完成后刷新 → 完成状态保留；4. localStorage 键值可验证。

## 6. 风险与开放问题
- localStorage 容量与多标签页同步不在范围（记录为非目标）。
