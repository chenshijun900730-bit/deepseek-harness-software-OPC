# PRODUCT_SPEC — TASK-20260815-001

> 负责人：Planner（deepseek-v4-pro / high）。批准前可反复修订；批准后修改将记录在案。

## 1. 产品目标

将演示应用首页的提交按钮背景色由灰色改为蓝色（#1e40af），提升按钮的视觉显著性，使用户能更清晰地识别可提交的操作入口。除背景色外，按钮的位置、尺寸、文案、禁用状态与提交行为均保持不变。

## 2. 用户故事

- 作为演示应用的演示者，当我打开应用首页时，我希望提交按钮以蓝色显示，以便观众能直观识别可点击的提交入口。
- 作为最终用户，当我在首页看到蓝色提交按钮时，我希望在未提交状态下能够点击它，并触发与改色前完全一致的提交行为。

## 3. 范围（In Scope）

- 仅修改首页提交按钮（id=submit）的计算样式背景色（background-color）。
- 目标背景色为蓝色 #1e40af（等价 rgb(30, 64, 175)）。
- 保持该按钮可点击、未提交时可交互的既有状态不变。

## 4. 非目标（Out of Scope）

- 不修改按钮的位置与尺寸。
- 不修改按钮文案、字体、圆角、边框、阴影等其他样式。
- 不修改提交逻辑、表单校验、接口调用或数据流。
- 不修改首页以外的任何其他页面或组件。
- 不引入任何新的依赖、UI 库或设计系统。

## 5. 可观察验收标准（草案，最终冻结于 SPRINT_CONTRACT.md）

1. 首页存在 id=submit 的提交按钮，该元素在 DOM 中可定位且可见。
2. 该按钮的计算样式 background-color 为蓝色 #1e40af（rgb(30, 64, 175)）。
3. 未提交状态下，该按钮仍可点击（disabled 属性为 false），点击后触发与改色前一致的提交行为。
4. 按钮的位置与尺寸（offsetLeft/offsetTop/offsetWidth/offsetHeight 或截图几何）与改色前一致，未因颜色变更产生布局位移。
5. 首页其他按钮的颜色未发生改变；首页以外页面无样式或行为回归。

## 6. 风险与开放问题

- 风险：若提交按钮颜色由共享样式规则控制，直接修改可能波及其他按钮。缓解：变更仅作用于 id=submit 的选择器，并以验收标准 5 验证其他按钮颜色不变。
- 风险：目标色 #1e40af 与页面既有配色协调性未知。缓解：该色值由需求方明确指定，按指定执行；若不协调，在批准阶段由需求方确认。
- 开放问题：无。
